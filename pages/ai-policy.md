Because accuracy is critical when running terminal commands or configuring hardware, I want to be transparent about how
I use Artificial Intelligence (AI) tools on this site.

[toc]

## Where AI _is_ used

* **Post outlines:** I may use AI to help brainstorm project structures and create initial outlines.
* **Code generation:** I may use AI to draft command-line snippets or scripts to solve problems I'm working on.

## Where AI _is not_ used

* **Copyediting:** I don't use AI to rewrite, proofread, or polish my content.
* **Unverified solutions:** I don't publish raw, unverified AI outputs or blindly trust generated commands.

## My commitment to accuracy

* **Hands-on verification:** Every single tutorial and command is manually tested and verified in my own lab
  environment to ensure it works exactly as described.

* **Accountability:** I take responsibility for all code, configurations, and technical advice provided on this site.
  I test everything beforehand; however, every environment is different. You should always run commands with caution in
  your own environment. There is no implied warranty with any information or advice on this site.
